v2.3.0 是 2.2.0 之后的正式版本，涵盖 Agent 稳定性与安全加固、桌面端多项修复、AI 引擎升级与 CI 基础设施更新。

## 🤖 Agent 稳定性与安全

- 消息不再静默丢失：上下文压缩失败时真实降级，purge 仅限当前会话
- 限制 Agent 的 turn 数、消息队列长度与文件读取大小，防止失控
- 安全加固：文件 API 鉴权、desktop 访问令牌校验、审批操作员校验；/permission 命令支持按渠道管理管理员

## 🖥️ 桌面端

- 修复 Windows 卸载误删用户数据（恢复 data-preserving 卸载行为）
- 修复 Windows 盘符根目录下文件预览/下载失败；文件页下载改用原生保存对话框
- 修复桌面启动时 dashboard 的 401 竞态；托盘图标、优雅退出（server.close 不再被强杀）
- NSIS 改用 lzma 压缩，安装包更小

## 🖼️ WebUI

- 修复聊天记录中的媒体链接在重启后失效：签名密钥持久化，读取时自动重新签名

## 🤖 AI 引擎

- 内置 pi-mono v0.82.1 → **v0.84.1**：新增 pi-telemetry 遥测包，同步本地补丁，依赖同步升级（mistralai 2.2.6、typebox 1.3.7、genai 1.52、bedrock 3.1048）

## ⚙️ CI 与部署

- Actions 全部升级至 Node 24 运行时，消除弃用警告
- Linux 构建启用 mold 快速链接器（约 2 倍提速）；缓存 NSIS 工具链
- Termux 部署脚本适配 pnpm 11：增量安装、sharp 改用系统 libvips

***

v2.3.0 is the stable release following 2.2.0: agent stability & security hardening, desktop fixes, an AI engine upgrade, and CI infrastructure updates.

## 🤖 Agent Stability & Security

- No more silent message loss: real degradation when compression fails, purge scoped to the current session
- Bounded agent turns, message queues, and file reads to prevent runaway execution
- Hardening: file API auth, desktop token validation, approval operator checks; /permission admin gate is now channel-aware

## 🖥️ Desktop

- Fixed Windows uninstall wiping user data (data-preserving uninstall restored)
- Fixed file preview/download on Windows drive-root paths; file-page downloads now use the native save dialog
- Fixed the dashboard 401 race on desktop launch; tray icon and graceful shutdown (server.close no longer force-killed)
- NSIS now uses lzma compression — smaller installer

## 🖼️ WebUI

- Fixed chat media links dying after restart: signing secret is persisted and links are re-signed on read

## 🤖 AI Engine

- Embedded pi-mono v0.82.1 → **v0.84.1**: new pi-telemetry package, replayed local patches, deps synced (mistralai 2.2.6, typebox 1.3.7, genai 1.52, bedrock 3.1048)

## ⚙️ CI & Deployment

- All Actions upgraded to the Node 24 runtime, deprecation warnings cleared
- mold fast linker on Linux (~2× faster linking); NSIS toolchain cached
- Termux deploy script adapted for pnpm 11: incremental install, sharp via system libvips
