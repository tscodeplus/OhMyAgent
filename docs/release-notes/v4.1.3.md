v4.1.3 is a patch release: the embedded pi-mono is upgraded to v0.87.1 (new frontier models + a Meta provider), and native-Windows computer-use plus skill-compliance false positives are fixed.

## ⬆️ pi-mono Upgraded to v0.87.1

- Synced upstream v0.86.0 → v0.87.1 with all local patches replayed; model catalogs add Claude Opus 5.5, GPT-6 Sol/Luna, Grok 4.7, MiMo v2.6 and more
- New Meta (Muse subscription) provider; z.ai "Prompt too long" is now recognized as context overflow; Cerebras no longer advertises strict tool schemas

## 🔧 Fixes

- **Fixed: computer-use's windows:local was permanently unavailable on native Windows.** The helper script path was unconditionally rewritten to WSL form, so the file landed in the wrong place, PowerShell exited without doing anything, and the client logged repeated "UIA server sent non-JSON line" warnings; path conversion now only happens under WSL
- **Fixed: false-positive compliance violations in the skill tracker** (ordinary wording and legitimate tool_search calls are no longer flagged)

## 🧹 Other

- Silenced the Fastify FSTDEP022 deprecation warning on startup; unsupported image_generation parameters removed from the skill prompt
