v2.2.0 (stable) completes the desktop migration from Electron to Tauri 2, ships native installers for all three platforms, and hardens the macOS/Windows experience.

## 🖥 Tauri 2 Desktop (Electron → Tauri)

- Migrate the desktop shell to **Tauri 2 + Node sidecar** — smaller footprint, native windows
- **Windows**: NSIS installer, hidden console window, tray/icon fixes, data-dir and update-check fixes
- **macOS**: drag-to-install dmg (hdiutil layout with /Applications symlink), UDBZ compression + unreachable-runtime pruning shrink the dmg, transparent splash window, first-run window deferral
- **Linux**: deb + AppImage (linuxdeploy packaging)
- Per-platform update metadata (`latest.yml` / `latest-mac.yml`) for the built-in updater

## 🔧 Desktop Fixes

- Service restart survives a hung graceful stop; server port reclaimed from orphaned sidecars on startup
- System language detected via `defaults` (GUI apps have no `LANG`); system proxy resolved via `scutil` so the updater reaches GitHub through ClashX-style proxies
- Update-check failures surface the GitHub 403 cause; external fetches send a User-Agent
- Tray shows a fixed "service error" label instead of raw error text
- App icon ring drawn as geometry so it stays centered
- Splash/error pages embedded in the bundle; shell i18n, title-bar theming, no startup flashes
- Remote-gateway mode loads the remote WebUI; `compat_*` command permissions granted on the remote-origin capability

## 🧪 Test Stability

- Rollback retry tests wait for the revert in-flight guard; oneshot parse test freezes the clock (23:59 flakiness)
- Full suite: 2521 tests passing

## ⚙️ CI

- New per-platform desktop workflows (Windows NSIS / macOS dmg / Linux deb+AppImage) with pinned rustc and reliable rustup + cargo caching
- CI trigger restored after the 2026-08-06 GitHub Actions outage

v2.2.0 正式版完成桌面端从 Electron 到 Tauri 2 的迁移，三平台原生安装包，并加固 macOS/Windows 体验。

## 🖥 Tauri 2 桌面端（Electron → Tauri）

- 桌面外壳迁移至 **Tauri 2 + Node sidecar**，体积更小、原生窗口
- **Windows**：NSIS 安装包、隐藏控制台窗口、托盘/图标修复、数据目录与更新检查修复
- **macOS**：支持拖拽安装的 dmg（hdiutil 布局 + /Applications 软链）、UDBZ 压缩并剪除不可达运行时文件以瘦身、透明 splash 窗口、首启主窗口延迟显示
- **Linux**：deb + AppImage（linuxdeploy 打包）
- 按平台生成更新元数据（`latest.yml` / `latest-mac.yml`），内置更新器可用

## 🔧 桌面端修复

- 服务优雅停止卡死时重启依然存活；启动时回收孤儿 sidecar 占用的服务端口
- 通过 `defaults` 检测系统语言（GUI 应用无 `LANG`）；通过 `scutil` 解析系统代理，更新器可穿透 ClashX 类代理访问 GitHub
- 更新检查失败时展示 GitHub 403 具体原因；外部请求携带 User-Agent
- 托盘"服务异常"固定文案，不再显示原始错误文本
- 应用图标 O 环改为几何绘制，始终居中
- splash/错误页内嵌进包；外壳 i18n、标题栏主题化、消除启动闪烁
- 远程网关模式加载远程 WebUI；remote-origin 能力授予 `compat_*` 命令权限

## 🧪 测试稳定性

- 回滚重试测试等待 revert 进行中守卫；oneshot 解析测试冻结时钟（消除 23:59 偶发失败）
- 全量测试：2521 通过

## ⚙️ CI

- 全新三平台桌面构建工作流（Windows NSIS / macOS dmg / Linux deb+AppImage），固定 rustc 版本并稳定缓存 rustup 与 cargo
