v2.3.0-beta1 将 Windows 安装包体积再缩减约 1/3，并大幅加快三平台 CI 构建速度。

## 📦 Installer 瘦身

- NSIS 压缩算法 zlib → **lzma**：Windows 安装包 68MB → **46MB**（实测）
- 清理项目中的 Electron 遗留引用与 .gitignore 过期条目

## ⚡ CI 加速

- 三平台启用快速链接器（Linux/macOS 用 mold，Windows 用 lld-link），CI 链接速度接近本地构建
- 链接器安装失败时自动回退默认链接器，不影响发布

***

v2.3.0-beta1 shrinks the Windows installer by ~1/3 and speeds up CI builds on all three platforms.

## 📦 Installer Slimming

- NSIS compression zlib → **lzma**: Windows installer 68MB → **46MB** (measured)
- Removed Electron-era leftovers and stale .gitignore entries

## ⚡ CI Speedups

- Fast linkers on all platforms (mold on Linux/macOS, lld-link on Windows) — CI links nearly as fast as local builds
- Linker install failure falls back to the default linker instead of breaking releases
