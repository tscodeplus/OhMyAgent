v4.3.1 fixes judge failure visibility and judge-chain confidence handling, fills in the related WebUI settings, and fixes OpenCode free-tier gateway rejections and Termux build OOM.

## 🧩 Judge Kernel

- **New: custom relay judges can carry an API key inline in the WebUI.** It is saved to config.yaml and picked up by hot reload, with the env-var name still working as a fallback; when both exist the inline key wins, and no process restart is needed
- **Fixed: local relay verdicts were always read as "low confidence".** Laya emits normalized entropy, which the Jev-calibrated gray-zone rules misread; it is now converted to Jev-faithful confidence before judging
- **Fixed: a judge failure gave no clue which tier broke.** Verdicts now record per-tier failure reasons (timeout, no key, parse error and so on) and the WebUI test panel shows them; gray-zone escalation, circuit opening and short-circuiting are logged too
- **Fixed: the WebUI timeout input reverted to the old value after saving.** A `timeout_ms` setting now sits next to the enable toggle and applies on save
- **Fixed: the enable row wrapped vertically on mobile; the model health bar gained a judge kernel health dot**
- OpenCode SystemOne calls now send the same session-fingerprint headers as the LLM path

## ⬆️ pi-mono Upgraded to pi v1.4.0

- System One gains image input (including per-model capability detection)
- New Client Identity layer that generates request attribution in one place
- Retry and provider fixes adopted: standalone status codes and Codex CLI stream drops are retried, rejected models are pruned, ChatGPT Business workspace limits and OpenRouter decision models are handled

## 🔧 Fixes

- **Fixed: the OpenCode free judge tier occasionally went entirely unavailable.** A 451 "endpoint is unavailable" now counts as a forced sunset like the other sunset signals and triggers the fallback
- **Fixed: gateway fingerprint checks and the free-tier gate rejected requests.** Requests now carry the official CLI's UA, client id and descending session id shape
- **Fixed: remote builds were OOM-killed on Termux.** tsc and vite exceeded Node's default ~1GB old-space limit (`Ineffective mark-compacts near heap limit`, exit 134); the build script now sets `--max-old-space-size=4096`
