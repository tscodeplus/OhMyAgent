v2.3.0-beta2 调整三平台 CI 链接器策略：只有实测有效的保留，无收益的回退默认链接器。

## 🔧 CI 链接器调整

- Linux 继续使用 **mold**：链接提速约 2 倍（实测 7m → 3m）
- Windows 回退默认链接器：lld-link 实测无加速（2m38s vs 2m37s），且修改 linker 会触发一次全量重编译，得不偿失
- macOS 回退默认 ld64：Apple clang 拒绝 `-fuse-ld=mold`，mold 在 macOS 上仅为实验性支持且无收益
- 链接器安装失败时自动回退默认链接器，不影响发布

***

v2.3.0-beta2 adjusts the CI linker strategy per platform — keep only what actually helps, fall back otherwise.

## 🔧 CI Linker Adjustments

- Linux keeps **mold**: ~2× faster linking (measured 7m → 3m)
- Windows reverts to the default linker: lld-link showed no speedup (2m38s vs 2m37s), and changing the linker triggers a one-time full rebuild for no benefit
- macOS reverts to default ld64: Apple clang rejects `-fuse-ld=mold`; mold on macOS is experimental only, with no gain
- Linker install failure falls back to the default linker instead of breaking releases
