v4.1.1 is a patch release: it fixes opencode / opencode-go model call failures and corrects the docs to describe the desktop shell as Tauri.

## 🔧 Fixes

- **Fixed: every opencode / opencode-go model call failed and silently fell through to fallback models.** Requests were missing the `x-opencode-session` headers required by the opencode gateways; they are now injected per upstream semantics

## 📄 Docs

- README (en/zh) desktop descriptions corrected from Electron to Tauri, reflecting the actual build (Tauri v2 shell + Node sidecar)
