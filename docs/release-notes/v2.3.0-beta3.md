v2.3.0-beta3 upgrades the embedded AI engine (pi-mono v0.82.1 → v0.84.1) and fixes Windows uninstall wiping user data.

## 🤖 AI Engine Upgrade

- pi-mono v0.82.1 → **v0.84.1**: new pi-telemetry package, replayed local patches (fallback-model retry loop, model registry, streamFn alias, etc.)
- Deps synced upstream: mistralai 2.2.6, typebox 1.3.7, genai 1.52, bedrock 3.1048
- Provider data: 21 updated, 2 new (baseten, qwen-token-plan-individual)

## 🛠️ Windows Uninstall Fix

- Dropped the NSIS post-uninstall hook that recursively removed `$INSTDIR\sidecar`, wiping runtime user data (SQLite, logs, generated images/videos) on uninstall/reinstall
- Default behavior restored: install-time files removed, runtime-created data kept
