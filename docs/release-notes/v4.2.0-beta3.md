v4.2.0-beta3 is the third beta of the 4.2 line: pi-mono is upgraded to v1.0.3, and MCP tools no longer disappear under certain intents.

## ⬆️ pi-mono Upgraded to v1.0.3

- Synced upstream v1.0.2 / v1.0.3 with all local patches merged cleanly
- Model catalog updates: the Azure provider is renamed (api id and env vars unchanged) and Foundry-deployed Azure Chat Completions is supported
- Upstream fixes adopted: Anthropic inline tool definitions, per-thinking-level sampling params, ChatGPT OAuth port-in-use error, Bedrock stale thinking-block drop and pricing tiers, Retry-After fallback

## 🔧 Fixes

- **Fixed: MCP tools vanished from the model-facing tool list under certain intents.** When a message matched a rule such as "web search", every `mcp__*` tool was filtered out, so `tool_search` served an MCP-less catalog and the model concluded the server was not enabled — while all 31 tools were in fact registered. MCP tools now survive under every intent
