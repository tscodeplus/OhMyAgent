v2.3.0-beta4 将 CI 的 GitHub Actions 全部升级到 Node.js 24 运行时，消除弃用警告。

## ⚙️ CI 基础设施

- Actions 升级至 Node 24 兼容版本：checkout v5、setup-node v5（显式关闭自动缓存，行为不变）、cache v5、upload-artifact v6、download-artifact v7、pnpm/action-setup v6
- 消除 GitHub 的 "Node.js 20 is deprecated" 警告，为 2026-09 的 Node 20 支持移除提前做好准备
- 构建产物与安装包无任何功能变化

## 🖼️ 聊天媒体链接修复

- 持久化的 /dl/ 下载链接在重启后失效（fallback 签名密钥每次进程随机生成）：读取时为图片重新签名，网关本地文件改用无过期的 /api/files/serve URL
- fallback 签名密钥持久化到 data/download-secret

***

v2.3.0-beta4 upgrades all GitHub Actions in CI to the Node.js 24 runtime, clearing deprecation warnings.

## ⚙️ CI Infrastructure

- Actions bumped to Node 24-compatible majors: checkout v5, setup-node v5 (auto-caching explicitly disabled — behavior unchanged), cache v5, upload-artifact v6, download-artifact v7, pnpm/action-setup v6
- Clears GitHub's "Node.js 20 is deprecated" warnings ahead of Node 20 support removal (Sep 2026)
- No functional change to builds or installers

## 🖼️ Chat Media Link Fix

- Persisted /dl/ download links in message history died on restart (the fallback signing key was random per process): images are now re-signed on read, and gateway-local files get permanent /api/files/serve URLs
- Fallback signing secret persisted to data/download-secret
