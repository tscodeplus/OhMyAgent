## ✨ 体验升级：更方便的设置，更美观的 UI

### 设置界面重构

- 设置重组为常规 / 智能体 / 集成 / 系统四大分组（带图标），新增设置搜索与子 Tab 导航，未保存更改在侧边栏显示徽章提醒，另加重启服务提示横幅
- 模型配置更省心：模型选择器支持从供应商 API **实时拉取最新模型列表**，也可直接手动输入任意模型 ID（自定义标识）；备用模型改为**拖拽排序**编辑器（带编号徽章），模型路由与记忆辅助两处统一；自定义供应商的模型增删改迁移为弹窗 + 成功 toast 流程
- Agent 编辑器新增返回按钮，且不再丢失未保存草稿
- 修复两处设置页 CPU 飙升（模型选择器无限重拉 ~30%、Agent 管理重渲染死循环 ~17%），打开设置不再风扇狂转

### 更美观

- 深色模式切换为 GitHub Dark 蓝调配色（#0d1117 背景），边框统一提亮、层次更清晰，长时间使用的可读性明显改善

### 移动端优化

- 设置页表格（Agent 列表、审批规则）支持横向滚动，右侧按钮不再被裁切
- 所有表单网格在手机上自动单列堆叠；下拉列表单列显示，不再重复文本
- 修复切换开关在手机上被拉伸成圆形的问题

### 输入界面优化

- 新增**斜杠命令面板**：输入框 / 按钮唤起，搜索过滤 + 键盘导航，命令与技能分组排序，短视口自动翻转方向
- 技能显式命令改为更清晰的 `/skill:<id>` 前缀
- 发送按钮在 Agent 运行时变为圆形停止按钮；用户主动停止不再误报「任务中断」错误
- 新会话居中欢迎布局，无会话直接发送自动建会话并接续

v3.1.0 is a full experience upgrade: settings are easier and the UI is better looking, with the embedded pi-mono upgraded to v0.84.4.

## ✨ Experience Upgrade: Easier Settings, Better-Looking UI

### Settings Restructure

- Settings reorganized into four icon groups — General / Agents / Integrations / System — with settings search, sub-tab navigation, unsaved-changes badges in the sidebar, and a restart banner
- Easier model configuration: the model picker fetches **live model lists from provider APIs** and accepts any manually typed model ID (with a custom badge); fallback models become a **drag-to-reorder** editor with numbered badges, unified across Model Routing and memory-assist tabs; custom provider model add/copy moved to a modal + success toast flow
- The Agent editor gains a back button that no longer discards unsaved drafts
- Fixed two settings-tab CPU spikes (infinite model-picker re-fetch ~30%, Agent Management re-render loop ~17%) — opening settings no longer spins the fans

### Better Looking

- Dark mode adopts a GitHub Dark blue palette (#0d1117 background) with brighter, consistent borders for clearly better long-session readability

### Mobile Optimization

- Settings tables (agent list, approval rules) scroll horizontally so right-side buttons are reachable
- All form grids stack to a single column on phones; dropdowns show single-column items without duplicated text
- Fixed toggles being stretched into circles on phones

### Chat Input Optimization

- New **slash command palette**: invoked from the / button with search, keyboard navigation, and grouped Commands/Skills; auto-flips on short viewports
- Explicit skill commands move to the clearer `/skill:<id>` prefix
- The send button becomes a circular stop button while the agent runs; user-initiated stops no longer show a spurious "task interrupted" error
- Centered welcome layout for new sessions; sending without a session auto-creates one and continues

## ⬆️ pi-mono Upgraded to v0.84.4

- openai-completions reasoning-details streaming fix, mistral fragment merge fix, cloudflare provider type cleanup
- Provider model catalogs synced to the npm v0.84.4 release (adds the deepseek-v4-flash-vision-exp experimental vision model)
- All local patches (tool-cycle guard, fallback loop, prompt compaction) replayed on top of the upstream refactor; zero dependency changes
