v2.2.0-beta1 rebuilds the desktop app with Tauri 2, slimming the installer and cutting resource usage.

## 🦀 Tauri 2 Migration

- Rebuild the desktop app on Tauri 2 (Rust), replacing Electron
- Smaller installer and lower memory footprint
- Splash screen, error pages and tray rebuilt natively

## 🖥 Desktop Fixes

- Fix updater failure dialog (surface GitHub 403 cause), reach GitHub through ClashX-style system proxies
- Tray shows a fixed "service error" label instead of raw error text
- Service restart survives a hung graceful stop; orphaned sidecar ports are reclaimed on startup
- Detect system language via `defaults` — GUI apps have no LANG
- Remote gateway mode loads the remote WebUI, not the embedded one

## 🤖 CI

- New desktop-windows and desktop-mac workflows build NSIS installer and dmg on GitHub Actions
- macOS x64 + arm64 builds, optional signing/notarization, cached cargo

v2.2.0-beta1 使用 Tauri 2 重构桌面端，缩小安装包并降低资源消耗。

## 🦀 Tauri 2 迁移

- 桌面端基于 Tauri 2（Rust）重建，取代 Electron
- 更小的安装包与更低的内存占用
- 启动画面、错误页与托盘原生重建

## 🖥 桌面端修复

- 修复更新检查失败对话框（显示 GitHub 403 原因），支持 ClashX 类系统代理访问 GitHub
- 托盘显示固定"服务异常"文案而非原始错误文本
- 服务重启不再被挂起的优雅停机卡住；启动时回收孤儿 sidecar 端口
- 通过 `defaults` 检测系统语言——GUI 应用没有 LANG
- 远程网关模式加载远程 WebUI 而非内置页面

## 🤖 CI

- 新增 desktop-windows 与 desktop-mac 工作流，在 GitHub Actions 上构建 NSIS 安装包与 dmg
- macOS x64 + arm64 双架构构建，可选签名/公证，cargo 缓存
