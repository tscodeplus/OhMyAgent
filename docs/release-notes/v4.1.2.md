v4.1.2 是 Windows 专项补丁版本：修复一键重启失效、控制台日志乱码与若干原生 Windows 兼容问题。

## 🔧 Windows 修复（主要更新）

- **修复：设置里一键重启服务在 Windows 上静默失效。** 辅助脚本启动方式与 pnpm shim 调用问题导致服务停了无人拉起；现经 WMI 交接使脚本独立存活并重放原命令行，一键更新脚本同步修复
- **修复：中文 Windows 控制台日志乱码。** 控制台输出改走 WriteConsoleW 路径，不受代码页影响
- **修复：Windows 原生兼容问题。** glob 不匹配 `\` 路径致路径拒绝列表失效；shell 工具中止/超时先清理进程树；`/tmp` 改用 `os.tmpdir()`
- 测试套件现可在 Windows 原生通过（此前仅 WSL）

## 🔧 其他修复

- 端口冲突时正确上报原始错误（此前被作用域外的 `stop()` ReferenceError 掩盖）
- 多模态设置里模型下拉不再被手风琴裁剪

v4.1.2 is a Windows-focused patch release: it fixes the silent one-click restart failure, console log mojibake, and several native-Windows compatibility issues.

## 🔧 Windows Fixes (Main Update)

- **Fixed: the settings "restart service" button silently did nothing on Windows.** The helper script's spawn mode and the pnpm shim call meant the server stopped with nothing bringing it back; the helper is now handed off via WMI to survive independently and replays the original command line, with the same fix in the perform-update script
- **Fixed: mojibake in console logs on Chinese Windows.** Console output now goes through the WriteConsoleW path, independent of the console code page
- **Fixed: native-Windows compatibility issues.** glob never matched `\` paths, silently disabling path deny lists; the shell tool cleans up the process tree on abort/timeout; literal '/tmp' replaced with os.tmpdir()
- The test suite now passes natively on Windows (previously WSL-only)

## 🔧 Other Fixes

- The original error is reported on port conflicts (previously masked by an out-of-scope `stop()` ReferenceError)
- Model dropdowns in Multimodal settings are no longer clipped by accordions
