v2.4.0-beta3 polishes Computer Use focus management and user-activity awareness: apps launch without stealing the foreground, focus is handed back after operations, and AppX activator and WebUI screenshot-render bugs are fixed.

## 🖥️ Computer Use (focus & foreground)

- Focus-free launch: launch-app starts apps in the background without stealing the user's current foreground
- Foreground hand-back: click-element restores the foreground after async host activation; focus returns when the task finishes
- macOS gets the same focus-free launch, user-activity guard, and foreground hand-back
- USER_ACTIVE guard now counts input events per second, no false idle detection

## 🖥️ Computer Use (fixes)

- Fixed WaitHwnd returning $null under the AppX activator, which broke every launch-app
- Fixed LASTINPUTINFO referenced as a top-level type (IdleMs declaration site)

## 🖼️ WebUI

- Fixed computer_use screenshots rendering 3× in desktop chat: now rendered once via tool output, matching webui_send_media
