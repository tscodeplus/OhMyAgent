v2.4.0 聚焦 Computer Use 的全面重构：Windows 输入切换为 UIA 无障碍优先的真实键鼠链路，macOS 从 JXA 迁移到原生 Swift AX 工具层；应用启动不再抢占前台，操作完成后归还焦点，并新增用户活动守卫。桌面端换上沉浸式左右分栏外壳，WebUI 会话支持自动生成标题与聊天导航 flyout。另修复 Agent 会话标题 / harness 优化器的 API key 传递与日志自愈问题。

## 🖥️ Computer Use — Windows UIA 真实输入

- 输入架构重构为「无障碍优先」：弃用侵入式 PowerShell 模拟，改为真实 UIA 输入（SetFocus、ValuePattern 等），桌面端全链路实测通过（记事本输入、窗口选择等）
- press_key 防 IME 干扰：走 ValuePattern 追加路径，绕过输入法拦截
- 新增前台抢占护盾与 no-touch 输入路径，不干扰用户当前操作
- launch-app 超时竞态修复；press-key 改为窗口级文档查找，Win11 记事本可用；CloseHandle 声明修正、校验定时器修复
- 工具描述补全工作流步骤、element_id 用法与截图语义，减少误用
- 新增 `scripts/verify-win-uia.ts` 端到端桌面验证脚本
- computer_use 截图直达 WebUI 聊天流

## 🖥️ Computer Use — macOS Swift AX 工具层

- 弃用不稳定的 JXA AX 桥接，替换为原生 Swift 工具，附带编译缓存
- 编译缓存改为 hash-keyed：AX 工具二进制按源码哈希存于应用支持目录，一次编译永久复用；原子替换 + 显式 COMPILE_FAILED 报错，杜绝 /tmp 清空或源码变动引发静默重编译导致的回归
- press_key Enter 优先提交聚焦元素的 AXConfirm，CGEvent 后台投递兜底——修复 Safari 智能搜索等后台场景回车失效；后台应用回车对齐最后文本目标
- 修复 macOS 15 下 Safari 空 AX 树的 AXActions 回归
- 修复后台启动、窗口捕获、跟随系统主题等 macOS 适配问题

## 🖥️ Computer Use — 无焦点启动与活动感知

- 无焦点启动：launch-app 后台启动应用，不再抢占用户前台；操作完成后归还焦点

- 修复 AppX 激活器下 WaitHwnd 返回 $null 导致 launch-app 全部失败

- computer_use 截图在桌面聊天中不再重复渲染 3 次，改经工具输出渲染一次，与 webui_send_media 一致

v2.4.0 centers on a full Computer Use overhaul: Windows input now runs through UIA accessibility-first real input instead of simulated keystrokes, and macOS moves from the JXA bridge to a native Swift AX tool layer. Apps launch without stealing the foreground, focus is handed back after operations, and a user-activity guard prevents false idle detection. The desktop shell gets an immersive split layout, and WebUI sessions gain auto-generated titles plus a chat navigation flyout.

## 🖥️ Computer Use — Windows UIA Real Input

- Reworked to accessibility-first input: dropped intrusive PowerShell simulation in favor of real UIA input (SetFocus, ValuePattern), verified end-to-end on the desktop (Notepad typing, window picking)
- IME-proof press_key via the ValuePattern append path, bypassing IME interception
- Foreground-steal shields and no-touch input paths keep user interaction undisturbed
- Fixed launch-app timeout race; press-key uses window-wide document lookup so Win11 Notepad works; CloseHandle declaration and verify timer fixes
- Tool description now documents workflow steps, element_id usage, and screenshot semantics
- Added `scripts/verify-win-uia.ts` for end-to-end desktop verification
- computer_use screenshots are delivered straight into the WebUI chat

## 🖥️ Computer Use — macOS Swift AX Tool Layer

- Replaced the flaky JXA AX bridge with a native Swift tool with a compile cache
- Hash-keyed compile cache: the AX binary is stored by source hash in the app-support dir — compile once per source, atomic move, explicit COMPILE_FAILED error; /tmp clears or source changes can never silently recompile over a patched binary
- press_key Enter prefers the focused element's AXConfirm before background CGEvent posting — fixes Safari smart-search Enter; Enter against background apps aligns with the last text target
- Fixed Safari's empty AX tree under macOS 15 (AXActions regression)
- Fixed background launch, window capture, and follow-system-theme issues

## 🖥️ Computer Use — Focus-Free Launch & Activity Guard

- Focus-free launch: apps start in the background without stealing the user's foreground; focus returns when operations finish
- USER_ACTIVE guard counts input events per second for accurate idle detection
- Fixed WaitHwnd returning $null under the AppX activator, which broke every launch-app
- Fixed LASTINPUTINFO referenced as a top-level type (IdleMs)
- computer_use screenshots render once via tool output (previously 3× in desktop chat), matching webui_send_media

## 🖼️ WebUI

- Auto-titled sessions: hover shows the full title with a theme-aware tooltip, only when truncated
- Chat navigation flyout from the collapsed rail; session title in caption
- Aligned /api/files/serve allowed roots with webui_send_media
- Stopped flooding chat with images from search tool outputs

## 💻 Desktop

- Immersive left-right split shell without a toolbar; brand logo, titleless collapsible tools drawer, unified chat entry
- Windows splash rounded-corner fix series: per-pixel alpha, transparent window backdrop, gray border removal
- Dropped unused windows-sys features; bundled Node aligned to 24.x

## 🔧 Agent & Infrastructure

- Provider API key is now passed to session-title generation and harness optimizer LLM calls (custom providers previously failed)
- Self-healing log transport recreates deleted log files without a restart
- Dependency housekeeping: unified typebox, dead deps removed, Vite v8; pi-mono VERSION marker synced to v0.84.1
