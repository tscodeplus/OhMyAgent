v2.4.0-beta1 将 Computer Use 全面重构为**非侵入式的 accessibility-first 控制**：不再移动光标、不再覆盖剪贴板、不再抢焦点，改为读取辅助功能树执行语义动作。

## 🖥️ Computer Use 重构

- **Windows**：新增常驻 UIA 服务（win-uia/），通过 Invoke/Value/Scroll 等 UI Automation 模式驱动元素动作；launch-app 不再激活已运行的实例（按 PID 枚举窗口），移除抢焦点的 SetFocus fallback
- **macOS**：通过 JXA 读取 AX 树；press_key 与滚动降级走 CGEventPostToPid 注入应用事件队列，按键无需应用处于前台
- **Linux**：AT-SPI 树 + 语义动作；SSH 动作层按平台拆分（linux/darwin/win32），本地与 SSH provider 共用同一层
- **Android**：新增 node provider（mimic HTTP 客户端 + adb 电源/锁屏管理），通过 `computerUse.node.url` 启用

## 📦 依赖与运行时

- 工具 schema 统一使用 typebox 包，移除 @sinclair/typebox 混用
- 删除死依赖（@opentelemetry/api、docxmlater、cronstrue、chalk）；sqlite-vec 平台包移入 optionalDependencies
- WebUI 升级 vite 8（与根 dev 中间件一致）、plugin-react 6、tailwind-vite 4.3
- 桌面端内置 Node 运行时升级至 24.19.0 LTS

## 🔧 其他

- 同步 pi-mono VERSION 标记至 v0.84.1（此前升级遗漏）

v2.4.0-beta1 rebuilds Computer Use as **non-intrusive accessibility-first control**: no cursor movement, no clipboard overwrite, no focus stealing — semantic actions driven off the accessibility tree on every platform.

## 🖥️ Computer Use Rework

- **Windows**: resident UIA server (win-uia/) driving element actions via Invoke/Value/Scroll patterns; launch-app no longer activates running instances (EnumWindows by PID), focus-stealing SetFocus fallback dropped
- **macOS**: AX tree via JXA; press_key and scroll degradation posted via CGEventPostToPid into the app's event queue, so keys land without the app being frontmost
- **Linux**: AT-SPI tree + semantic actions; SSH action layer split per platform (linux/darwin/win32), shared by local and SSH providers
- **Android**: new node provider (mimic HTTP client + adb power/lock-screen management) behind `computerUse.node.url`

## 📦 Dependencies & Runtime

- All tool schemas unified on the typebox package; @sinclair/typebox mix removed
- Dead deps dropped (@opentelemetry/api, docxmlater, cronstrue, chalk); sqlite-vec platform packages moved to optionalDependencies
- WebUI upgraded to vite 8 (matches root dev middleware), plugin-react 6, tailwind-vite 4.3
- Desktop bundled Node runtime bumped to 24.19.0 LTS

- pi-mono VERSION marker synced to v0.84.1 (missed in the earlier upgrade)
