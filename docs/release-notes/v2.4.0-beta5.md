v2.4.0-beta5 聚焦桌面端沉浸式外壳与会话标题体验：主窗口改为无边框设计，导航收进侧边栏并可折叠为图标栏；会话列表恢复自动标题，悬停显示随主题适配的完整标题提示。

## 🖥️ Desktop Shell（沉浸式无边框窗口）

- 主窗口改为无边框（Windows/Linux），标题栏由 WebUI 绘制：顶部右侧提供拖拽区域与最小化/最大化/关闭按钮；macOS 保留系统原生红绿灯（TitleBarStyle::Overlay）
- 新增 maximize 切换命令与 isMaximized IPC，窗口状态实时同步
- 应用导航从顶部工具栏移入侧边栏；侧边栏可折叠为 56px 图标栏，视口小于 1024px 时自动折叠
- 品牌 Logo 移入侧边栏并放大至 24px
- 新增可折叠工具抽屉（skills/files/memory/cron/dashboard），紧凑 28px 行高、无间距；折叠开关为整行居中的 chevron 切换，状态经 localStorage 持久化
- 原 对话/对话空间 分栏合并为固定的「对话」入口，侧边栏获得更多空间

## 💬 会话标题与提示

- 恢复会话自动标题（3-15 字，跟随用户语言，由对话 LLM 生成）
- 悬停会话行显示完整标题提示：主题感知（亮/暗双主题），150ms 淡入，单行显示在标题同一水平位置，并脱离侧边栏滚动容器
- 仅当标题被截断时弹出提示（scrollWidth 对比 clientWidth），短标题不再打扰

v2.4.0-beta5 focuses on the immersive desktop shell and session-title experience: the main window is now frameless with navigation folded into a collapsible sidebar, and session lists regain auto-titles with theme-aware full-title tooltips on hover.

## 🖥️ Desktop Shell (frameless immersive window)

- Frameless main window on Windows/Linux: the caption is drawn by the WebUI (drag region + minimize/maximize/close at the top right); macOS keeps the native traffic lights via TitleBarStyle::Overlay
- New maximize toggle command and isMaximized IPC keep window state in sync
- App navigation moved from the top toolbar into the sidebar; the sidebar collapses to a 56px icon rail and auto-collapses below a 1024px viewport
- Brand logo moved into the sidebar and enlarged to 24px
- New collapsible tools drawer (skills/files/memory/cron/dashboard) with compact 28px rows; the collapse control is a full-width centered-chevron toggle persisted via localStorage
- The split 对话/对话空间 entries merged into a single pinned 对话 section, giving the chat list more room

## 💬 Session titles & tooltips

- Restored auto-titles for sessions (3-15 chars, follow the user's language, generated by the conversation LLM)
- Hovering a session row shows the full title in a theme-aware tooltip (light/dark), 150ms fade-in, single line at the title's level, escaping the sidebar scroll container
- The tooltip only appears when the title is truncated (scrollWidth vs clientWidth), so short titles stay quiet
