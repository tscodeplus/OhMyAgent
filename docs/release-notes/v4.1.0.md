v4.1.0 是记忆系统专项版本：修复中文记忆检索质量、删除残留与辅助模型配置痛点，新增项目级记忆与 DreamCycle 补跑。

## 🧠 记忆系统修复与增强（主要更新）

- **修复：纯中文记忆无法提取检索词。** 分词器新增 jieba 中文分词（过滤停用词），此前纯中文记忆 9.5% 完全提取不到词条，导致检索召回缺失
- **修复：删除记忆后派生存储残留。** 删除现在集中清理词条、链接、嵌入向量与 vec0 行（旧路径部分未开启外键级联，虚拟表无 FK）；项目/会话删除同样走 repository 触发清理
- **新增：项目级记忆写入 + WebUI 多维筛选。** memory-store 工具新增 scope 参数（user/project），项目记忆按 WebUI 项目 ID 归档、检索自动召回；记忆页新增 kind / channel 筛选与 scope 修正（project 精确匹配，不再误匹配渠道 ID）
- **修复：memory_aux_models 修改后必须重启。** 辅助模型链与输出语言改为配置热更新（configEventBus），改完即生效
- **修复：辅助模型误用主供应商密钥。** 仅在 provider_keys 配置的供应商现在正确解析 key/baseUrl，不再被无关端点 401 拒绝
- **新增：DreamCycle 补跑与自愈。** 启动时若上次夜间运行超 24h（或从未运行）立即补跑全阶段；memory_doctor 默认启用（孤儿词条修复、覆盖率检查）；新增 terms_backfill 定时回填任务
- **新增：记忆管线可观测。** 观测 API 与面板计数器（24h 降级计数、自上次运行以来的事件数）；迁移 v7 统一时间戳为 epoch-ms

## 🖥️ WebUI 修复

- **修复：开发模式下旧构建产物遮蔽源码改动。** 开发环境优先使用 Vite HMR 中间件，ui/dist 仅在生产（桌面 sidecar）或显式指定时使用——此前边改边看常显示旧页面，重建时甚至白屏
- 记忆详情抽屉友好渲染：hygiene_checkpoint（内部书签，禁编辑）、persona（人类可读摘要）、scene（解析为 Markdown 摘要正文）不再显示原始 JSON/文件路径；治理编辑块对机器管理行隐藏，API 层同步拒绝篡改

v4.1.0 is a memory-system focused release: it fixes Chinese retrieval quality, deletion residue, and aux-model config pain points, and adds project-scoped memories plus DreamCycle catch-up.

## 🧠 Memory System Fixes & Enhancements (Main Update)

- **Fixed: pure-Chinese memories extracted no retrieval terms.** The tokenizer now segments Chinese with jieba (stop-words filtered); previously 9.5% of pure-Chinese memories produced zero terms, hurting recall
- **Fixed: deleting a memory left residue in derived stores.** Deletion now centrally removes terms, links, embeddings and vec0 rows (some legacy paths ran without FK cascade; virtual tables have none); project/session deletion goes through the repository too
- **New: project-scoped memory writes + WebUI filters.** The memory-store tool gains a scope arg (user/project); project memories archive by WebUI project id and are recalled automatically; the memory page gains kind/channel filters and an exact-match project scope
- **Fixed: memory_aux_models changes required a restart.** The aux model chain and output language hot-reload via configEventBus — changes apply immediately
- **Fixed: aux models fell back to the primary provider's key.** Providers configured only in provider_keys now resolve their own key/baseUrl instead of getting 401s from an unrelated endpoint
- **New: DreamCycle catch-up & self-healing.** On startup, if the last nightly run is >24h old (or never ran), all phases run immediately; memory_doctor is default-enabled (orphan-term repair, coverage checks); a terms_backfill job backfills terms on a schedule
- **New: memory pipeline observability.** Observability API and panel counters (24h degradation window, events since last run); migration v7 normalizes timestamps to epoch-ms

## 🖥️ WebUI Fixes

- **Fixed: stale build artifacts shadowed source edits in dev mode.** Dev now prefers the Vite HMR middleware; ui/dist is served only in production (desktop sidecar) or when explicitly pointed at — previously hot-reload showed old pages and rebuilds blanked the site
- Friendly memory detail drawer: hygiene_checkpoint (internal bookmark, editing disabled), persona (human-readable summary) and scene (resolved Markdown digest) rows no longer show raw JSON/file paths; governance editing is hidden for machine-managed rows and rejected at the API layer

## 💻 Desktop

- The splash label follows the language configured in-app (it previously read only the system locale, so switching to English still showed Chinese after restart)
